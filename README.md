# 🎮 GameHub - Python GUI Game Suite

**GameHub** is a comprehensive desktop game application developed in Python, featuring an intuitive graphical user interface that brings together six engaging games in one dynamic platform. Designed for entertainment and casual gaming, GameHub offers a diverse collection of games suitable for players of all ages.

---

## 🎯 Featured Games

- 🔮 **Lucky Guess** - A number guessing game that tests your intuition and luck
- 📚 **Quiz Game** - Challenge your knowledge with interactive trivia questions
- 🧠 **Memory Game** - Sharpen your memory skills by matching pairs of cards
- ⭕ **Tic Tac Toe** - The classic strategy game with an AI opponent
- ⚽ **Bouncy Ball** - Fast-paced action gameplay with dynamic ball physics
- 🏎️ **Car Racing** - Thrilling racing experience with engaging mechanics

---

## ✨ Key Features

- 🖥️ **Clean, User-Friendly GUI** - Built with Python (Tkinter/PyGame)
- 🎮 **Multiple Game Modes** - Varied entertainment options
- ⚡ **Smooth Animations** - Responsive controls and dynamic visuals
- 📊 **Scoreboard & Statistics** - Track your gaming progress
- 🧭 **Intuitive Navigation** - Easy game selection and menu system
- 🖇️ **Cross-Platform Compatible** - Works on Windows, macOS, and Linux

---

## 🚀 Getting Started

### Prerequisites
- Python 3.7 or higher
- Tkinter (usually comes with Python)
- PyGame (for graphics and animations)

### Installation

```bash
# Clone the repository
git clone https://github.com/Ram050106/Gamehub.git

# Navigate to the project directory
cd Gamehub

# Install required dependencies
pip install -r requirements.txt
```

### Running the Application

```bash
python main.py
```
